# Dr. Ramkumar P.B. — Academic Portfolio

A responsive, static personal portfolio built with **HTML, CSS and vanilla JavaScript**.

## Repository structure

```text
ramkumar-academic-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
├── .gitignore
└── assets/
    └── profile.png
```

## Run locally

No build tools, package manager or server are required.

1. Download and extract the repository ZIP.
2. Open `index.html` in a modern browser.

For local development, you may also serve the folder with any static HTTP server.

## Deploy

This is a static site and can be deployed directly to GitHub Pages, Netlify, Cloudflare Pages, or any standard web server. Publish the repository root as the site directory.

## Customize

- Update page content in `index.html`.
- Adjust colors, layout and responsive styles in `style.css`.
- Edit navigation and email-copy interactions in `script.js`.
- Replace `assets/profile.png` to use another portrait. Keep the same filename or update the image path in `index.html`.

## Privacy note

The public portfolio intentionally omits personal details such as date of birth and private mobile number. Review all public-facing information before deployment.

## Credits and dependencies

Built with semantic HTML, CSS and vanilla JavaScript. Google Fonts are loaded from Google Fonts when an internet connection is available; the site otherwise falls back to system fonts.
